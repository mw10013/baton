Repository architecture · observed from source

Baton is a shop-scoped production system.

A TanStack Start Worker authenticates people and routes requests. One durable ShopAgent per Shopify shop owns operational state, live subscriptions, and workflow execution. D1 remains the shared identity and installation store.

04 · Data ownership

Uncertainties and runtime-only questions

  • This explainer is based on static source inspection; Shopify auth, billing, WebSockets, D1 replicas, and workflow retries were not exercised.
  • Subscription lapse is discovered on plan revalidation, not by an independent scheduled poll found in the repository.
  • The order-delete webhook path appears idempotent through repeated mark/delete behavior, but it does not use the explicit webhook-ID dedupe path used by create/update topics.
  • Cloudflare hibernation and workflow retry timing depend on platform behavior outside this repository.
