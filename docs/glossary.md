# Glossary

The architectural vocabulary for this repo. Use these words in code, docs, and conversation. Where Effect, Cloudflare, or TanStack has a term, we use theirs.

**This is not the product's domain language.** That is legacy's vocabulary (run, task, workflow, team, member, counted order, …), ported with the domain modules under `src/domain/`; its section is [Domain](#domain), at the end, speaking legacy's words.

## Source layout

`src/` is split by runtime, then by role. Effect's reference app (`refs/effect/ai-docs/src/51_http-server/fixtures`) splits `domain/`, `api/` and `server/`; we keep its idea and name the parts by where they run.

| Path              | Holds                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/contract/`   | The **API definition**: the schemas and errors that cross a boundary (the Backend's methods, the actor's socket `RpcGroup`s, `DevRpcs`, the fixture). Schemas only. Imported by both Workers and the browser.                                                                                                                                                                                                                 |
| `src/domain/`     | The product's model as pure Schema and pure functions: entities, branded ids, rules and their tables, in one file per bounded context (`platform`, `orders`, `shop-work`; `billing` arrives with its slice), ported from legacy, plus `workflow-layout.ts` (legacy's `WorkflowLayout`, the step arithmetic) inside shop work. Imports only `effect` and the sibling contexts its map allows; `src/contract/` imports from it. |
| `src/backend/`    | The Backend Worker, its schemaless methods, services, repositories and the actor. Also the stack-time code (`stack.ts`, `stage.ts`, `resources.ts`, `seed.ts`).                                                                                                                                                                                                                                                               |
| `src/web/`        | The Website: `routes/` (TanStack file routes), `components/` (with `screen/` as the only home of layout), `client/` (the browser's actor socket), `server/` (server functions).                                                                                                                                                                                                                                               |
| `src/web/server/` | The Website's **server functions**: TanStack `createServerFn`s that decode their input with Schema and call the Backend's methods over the binding. No Effect runtime.                                                                                                                                                                                                                                                        |

Tests mirror this under `test/{unit,browser,integ,e2e}/`.

## Terms

| Term                     | Meaning                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | Avoid                                                                                      |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| **Website**              | The TanStack Start Worker (Alchemy `Website.Vite`). It serves SSR pages, static assets, server functions and the actor upgrade route. Plain TypeScript, with no Effect runtime; Effect runs in the browser only for the actor socket.                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | "frontend" (the browser is the front end), "foreground"                                    |
| **Backend**              | The private Effect Worker (Alchemy `Cloudflare.Worker`, `workersDev: false`). It returns its **schemaless methods** beside `fetch`, serves Better Auth and `DevRpcs` on `fetch`, and hosts the actors behind its **gate**.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | "background task", "server", "API Worker"                                                  |
| **Binding**              | The service binding `env.BACKEND` from Website to Backend.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |                                                                                            |
| **API definition**       | `src/contract/`: the schemas and errors both sides of a boundary share.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | "schema" (too broad)                                                                       |
| **Server function**      | A TanStack `createServerFn` in `src/web/server/`: plain async TypeScript that validates its input with Effect Schema, calls a **schemaless method** on the Backend with the visitor's cookie, and returns plain data. Loaders, guards and Backend-owned writes call one.                                                                                                                                                                                                                                                                                                                                                                                                                                  | Using it for an actor procedure                                                            |
| **Schemaless method**    | A method an Effect Worker or Durable Object returns beside `fetch`, called over a binding or a stub with Cloudflare's own RPC and no schema on the wire (`toRpcAsync` from the Website, the typed stub from the Backend). It decodes its arguments itself; a typed failure crosses as a plain `{ _tag }` object the caller decodes.                                                                                                                                                                                                                                                                                                                                                                       | "endpoint", "procedure"                                                                    |
| **Procedure**            | One `Rpc.make(...)` in a group, served on the actor's socket. A caller sends a **payload** and gets back a **success** or a **failure**.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | "endpoint" (an HttpApi term), "method"                                                     |
| **Group**                | An `RpcGroup` of related procedures: the actor's `MemberRpcs` and `MerchantRpcs`, and `DevRpcs`; integ adds `IntegRpcs` on its test Backend.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |                                                                                            |
| **Handler**              | The implementation of a procedure: it decodes the call (the RPC server does it from the procedure's schema) and dispatches to an **application service**'s method, as the actor's `ShopActorRpcs.toLayer` does. It holds no rule of its own.                                                                                                                                                                                                                                                                                                                                                                                                                                                              |                                                                                            |
| **Area**                 | One part of shop work with its own storage and use cases: orders, membership (members, teams, who is on which team), workflows and runs. Each has a **repository** and an **application service**.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |                                                                                            |
| **Repository**           | One store's SQL for one area and nothing else, named `<Area>Repository`: `MembershipRepository` and `ShopSessionRepository` over D1, `makeOrderRepository` and `makeWorkflowRepository` over the actor's SQLite.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | "store" for the service, "DAO"                                                             |
| **Application service**  | An area's use cases, named by the area's bare name (`makeOrders`, `makeMembership`, `makeWorkflows`): it checks rules across stores, calls the repository, follows up (closes sockets, reconciles, notifies) and answers. Built once per actor activation.                                                                                                                                                                                                                                                                                                                                                                                                                                                | "agent" (legacy's Agents SDK name), "manager"                                              |
| **Workflow**             | Alone, always the product's definition (steps of tasks; see [Domain](#domain)). Cloudflare's is always the **orders sync Workflow** (`OrdersSyncWorkflow`), and a handle on it is `ordersSync`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | "workflow" for the orders sync Workflow                                                    |
| **Client**               | `ShopActorClient`, the browser's `AtomRpc` service that calls the actor's procedures over its socket.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |                                                                                            |
| **Transport**            | What carries a call: the service binding for a schemaless method, the actor's WebSocket for a procedure.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |                                                                                            |
| **Boundary**             | Any point where data enters a process (browser ↔ Website, Website ↔ Backend, browser ↔ actor). Data is **decoded** with Schema there.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | "IPC"                                                                                      |
| **Failure**              | An expected, typed error: a `Schema.TaggedError` a procedure or method declares.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | "exception"                                                                                |
| **Defect**               | An unexpected error (a bug). Over a binding it rejects as an `Error`; over the socket it round-trips as a defect.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | "crash"                                                                                    |
| **Registry**             | The `AtomRegistry` owned by the router. Only the actor socket's atoms live in it.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | "store", "cache"                                                                           |
| **Query atom**           | `ShopActorClient.query(...)`: reads a procedure's result over the socket.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |                                                                                            |
| **Mutation atom**        | `ShopActorClient.mutation(...)`: calls a procedure that changes something.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |                                                                                            |
| **Reactivity key**       | A label a **notice** invalidates and that queries refetch on.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | "cache tag"                                                                                |
| **Seed (atom)**          | Filling a socket query atom in the browser with data the page's loader already has (`seedShop`), so the page shows it at once and the socket only keeps it current.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | "prefetch" (TanStack uses that for intent preloading), "prime"                             |
| **Actor**                | A Cloudflare Durable Object, named `<Key>Actor` (e.g. `ShopActor`): one live instance per key, private SQLite state, one message at a time. It is a runtime unit. Hosted by the Backend. It owns its key's data: `ShopActor` holds the Backend's own `ShopSessionRepository` and `ShopifyAdmin`, fetches an order from the Admin API itself and creates the orders sync Workflow's instances. Two surfaces that never overlap: browsers call its procedures over a WebSocket at `/api/actor/<key>`; the Backend and the Workflow call its schemaless methods on the stub. Who is on a socket lives in that socket's attachment and tags, written when the socket is accepted, so it survives hibernation. | "agent" (Agents SDK, LLM), "DO", "server". Never the signed-in user (that is a **member**) |
| **Entity** (provisional) | The domain-model sense only: a thing identified by its id, in `src/domain/`. The term is not settled for this repo. It is not the runtime unit, and not Effect Cluster's `Entity`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | Using it for an **Actor**                                                                  |
| **Notice**               | A frame an actor pushes to its sockets naming the reactivity keys to invalidate (`Notice`); never carries data.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | "event", "broadcast message"                                                               |
| **Shop**                 | One Shopify store, the tenant: a `ShopSession` row keyed by its myshopify domain, Baton's `Shop`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | "store", "tenant" in code                                                                  |
| **Shop key**             | The myshopify domain that names a shop's `ShopSession` row and its actor; `ShopKey`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |                                                                                            |
| **Browser**              | The person's browser running our page, holding one socket to a shop's actor.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | "tab", "client" (that is the `AtomRpc` service)                                            |
| **Member**               | Baton's sense: a `Member` row, one email's membership of one shop. An address may sign in only if it is a member of some shop. Replaces the old invite-list meaning.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | "user" for a member                                                                        |
| **Merchant**             | Whoever presents a Shopify session token for the shop (the store owner inside the Shopify admin). In the Shopify admin App Bridge supplies it; integ and unit tests sign one with the fake app's secret.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |                                                                                            |
| **Admin**                | A Better Auth user with `role = 'admin'`: us, running the site. Never a member; the gate refuses an admin a shop.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | "operator"; "admin" alone for Shopify's                                                    |
| **Shopify admin**        | Shopify's merchant UI, where the app is embedded.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | "the admin" for Shopify's                                                                  |
| **Caller**               | Who is on an actor socket: a member or a merchant; `ConnectionCaller`, Baton's `CallerRole`. Procedures are named for their role (`Member…`, `Merchant…`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |                                                                                            |
| **Gate**                 | The Backend's check of a credential against a shop (`ShopAccess`). On an upgrade it names the caller in the **gate header** or closes the socket at once with a close code (4401, 4403, 4404, 1013); for a page's loader it answers `shopSnapshot`.                                                                                                                                                                                                                                                                                                                                                                                                                                                       |                                                                                            |
| **Gate header**          | `x-actor-connection`: the JSON caller the gate puts on the upgrade it forwards to an actor, on a request it rebuilds from nothing, so a browser cannot set it. The actor reads it once, when it accepts the socket.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |                                                                                            |
| **Stub**                 | The Durable Object stub the Backend holds for one actor (`getByName`). The Backend calls the actor's schemaless methods (`revoke`, `snapshot`, `syncOrderWebhook`, `listOrders`, …) on it and forwards upgrades through it; the orders sync Workflow calls its callbacks (`onOrdersStream`, `onOrdersSyncEmpty`, `onOrdersSyncError`) on it; never a socket.                                                                                                                                                                                                                                                                                                                                              |                                                                                            |
| **Socket holder**        | `ShopSocket`, in a layout: the one component that names a tab's actor socket and keeps it open while the layout is mounted (the `/app` layout for a merchant, the member shop layout for a member), with the socket's banner above the pages. Pages seed and read the socket's atoms and never name it.                                                                                                                                                                                                                                                                                                                                                                                                   | "the page's socket"                                                                        |
| **Member ceiling**       | `ShopLimits.maxMembers` (50) on any plan: Add member refuses a new email at it (`MemberCeilingError`, "A shop can have 50 members."); re-adding an existing member never does. Billing's seats count members, they do not refuse them.                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | "seat limit"                                                                               |
| **Team limit**           | `ShopLimits.maxTeams` (50): Create team refuses past it (`TeamLimitError`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | "team cap"                                                                                 |
| **App nav**              | `s-app-nav` in the `/app` layout: the Shopify admin's left-nav entries for the app (Home, Orders, Workflows, Teams, Members). App Bridge hoists it out of the frame; a click reaches the layout's `shopify:navigate` bridge, which navigates in the frame with the search the `/app` guards need.                                                                                                                                                                                                                                                                                                                                                                                                         | "sidebar", "menu"                                                                          |
| **Environment**          | A role the stack plays: `dev`, `test`, `e2e` or `staging`. It picks a stage's seed file, state store (local for `dev`, `test` and `e2e`; Cloudflare for `staging`) and policy. A stage whose environment is not listed fails.                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | "env" in code (that is `.env`, `process.env` or a Worker's bindings), "kind", "type"       |
| **Stage**                | One isolated copy of the stack in an environment, with its own state, names and data. Named `<environment>-<user>[-wt-NN]` with dashes (`dev-mw`, `dev-mw-wt-01`, `test-mw`, `e2e-mw-wt-01`); the shared `staging` stage is named after its environment. `node scripts/stage.ts <environment>` prints this checkout's.                                                                                                                                                                                                                                                                                                                                                                                    | Underscores (`dev_mw`)                                                                     |
| **Stage config**         | The values another service issues for a deployed stage (today the Shopify app's key and secret): `.env.<stage>` in the main checkout, saved by the stage config stack (`stacks/stage-config.ts`) as its output record for that stage, which the app stack reads on that stage. Deployed by hand; holds no resources.                                                                                                                                                                                                                                                                                                                                                                                      | "secrets" (it holds public values too), "stage env"                                        |
| **Seed (data)**          | The rows a stage starts with: its environment's one file under `seed/`, run by the `Seed` Action after Better Auth's migration. Every environment's seed is its admin; `test`'s also carries the integration tests' fake shops. Idempotent: it inserts what is missing.                                                                                                                                                                                                                                                                                                                                                                                                                                   |                                                                                            |
| **Fixture**              | A known state one installed shop is put into, on demand: `ShopFixture`, loaded by `LoadFixture` in `DevRpcs` on `/api/dev` (dev, test and e2e only), which replaces that shop's members, teams, workflows and orders; `AddToFixture` adds beside them. The dev fixture is `fixture.ts`; `vp run fixture` loads it, store half included.                                                                                                                                                                                                                                                                                                                                                                   | "seed" for a shop's data                                                                   |

## Domain

The product's words, legacy's, seeded from the nouns tables of the context files under `src/domain/`. Each word means one thing in its context; the full vocabulary (states, verbs, screen words and the rules) lives in each context file's top-of-file JSDoc, with the map of contexts and their import direction at the top of `src/domain/platform.ts`. A symbol named here that has no file yet (`ShopAgent`, `useLiveQuery`, the repositories) arrives with its slice.

| Word                 | Meaning                                                                                                                                                                                                           | Context   | Symbol                                                                                                         |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------- | -------------------------------------------------------------------------------------------------------------- |
| **shop**             | one Shopify store, the tenant                                                                                                                                                                                     | platform  | `ShopSession`, `ShopKey`                                                                                       |
| **ceiling**          | a per-shop limit the object enforces: `maxOpenOrders`, `maxMembers` on `ShopLimits`                                                                                                                               | platform  | `ShopLimits`                                                                                                   |
| **memo**             | a list read's last answer, kept in the object's memory until the next publish                                                                                                                                     | platform  | `makeRuns`' memos (the orders index and the workflows list)                                                    |
| **socket**           | a tab's one WebSocket to its shop's object, for the life of the tab; a series of connections                                                                                                                      | platform  | `ShopAgentSocket`, `ShopAgentSocketProvider`                                                                   |
| **connection**       | the object's end of one socket, from identify to close; carries who is on it                                                                                                                                      | platform  | `ConnectionState` in ShopWork, `ConnectionRole`                                                                |
| **identify**         | the object learns who is on a connection from the gate's headers, once, at connect; the tab learns the handshake landed                                                                                           | platform  | `ShopAgent.onConnect`, `identified`                                                                            |
| **publish**          | a write that succeeded telling every connection to re-read; the sites table on `ShopAgent.publish` lists the writes                                                                                               | platform  | `ShopAgent.publish`, `ShopAgentHost.publish`                                                                   |
| **invalidation**     | the one message the object sends: re-read; never the data                                                                                                                                                         | platform  | `InvalidatedMessage`, `INVALIDATION_THROTTLE_MS`                                                               |
| **live**             | a screen whose rows other actors change and the object re-reads on every publish: the orders index, the order page, the home page's orders strip, the workflows list, the member's workflow page                  | platform  | `useLiveRead`, the reads seeded by loaders                                                                     |
| **revoke**           | the object closing a connection whose identity no longer holds (membership, team, app subscription), so the tab reconnects through the gate                                                                       | platform  | `CONNECTION_CLOSE_REVOKED`, `revokeAllConnections`                                                             |
| **displace**         | the object closing a member's oldest connection because a newer one took the last of `maxConnectionsPerMember`; the screen stays closed                                                                           | platform  | `CONNECTION_CLOSE_DISPLACED`, `displaceConnections`                                                            |
| **order**            | a Shopify order                                                                                                                                                                                                   | orders    | `ShopOrder`                                                                                                    |
| **item**             | one line item of an order                                                                                                                                                                                         | orders    | `OrderLineItem`                                                                                                |
| **webhook**          | Shopify telling Baton an order or the app changed, verified by HMAC; an order webhook syncs that one order                                                                                                        | orders    | `Webhooks`, `WebhookTopic`, `validateWebhook`                                                                  |
| **sync**             | making Baton's copy of an order agree with Shopify: a webhook (one order, as it happens), the open-orders sync (the button: open, unfulfilled, created in the last 30 days), or the merchant asking for one order | orders    | `syncOrder`, `ShopAgent.syncOpenOrders`, `OrdersSyncResult`, `OrdersSyncStatus`, `SyncState`, `SyncOrderInput` |
| **current quantity** | Shopify's count of units still on the item after edits and refunds                                                                                                                                                | orders    | `OrderLineItem.currentQuantity`                                                                                |
| **merchant**         | the shop's owner, acting from the Shopify admin                                                                                                                                                                   | shop work | `Actor` role `merchant`                                                                                        |
| **member**           | a person at the bench, on one or more teams                                                                                                                                                                       | shop work | `Actor` role `member`, `Member`                                                                                |
| **team**             | the group a task is assigned to                                                                                                                                                                                   | shop work | `Team`                                                                                                         |
| **workflow**         | the definition: steps of tasks                                                                                                                                                                                    | shop work | `Workflow`, `WorkflowTask`                                                                                     |
| **step**             | a position in a workflow; its tasks are done in parallel                                                                                                                                                          | shop work | `WorkflowTask`, `RunTask` field                                                                                |
| **run**              | one item going through one workflow                                                                                                                                                                               | shop work | `Run`                                                                                                          |
| **task**             | one unit of work on a run, on one team                                                                                                                                                                            | shop work | `RunTask`                                                                                                      |
| **block**            | a person's hold on a run                                                                                                                                                                                          | shop work | `runIsBlocked`                                                                                                 |
| **note**             | free text on a run                                                                                                                                                                                                | shop work | `RunNote`                                                                                                      |
| **draft**            | the workflow's edited copy of its tasks, from Edit until Apply or Discard; one or none                                                                                                                            | shop work | `Workflow` field `draftTasks`                                                                                  |
| **filter**           | one axis of a list with a fixed set of values; the list shows the rows matching every chosen filter                                                                                                               | shop work | `OrdersShow`, `WorkflowsListState`, `WorkflowsIndexState`, `ListOrdersInput`, `RunQuery`                       |
| **count**            | how many rows a filter value would show, given the other filters and never the search                                                                                                                             | shop work | `OrderCounts`, `RunListCounts`                                                                                 |
| **search**           | free text matched against a row's order number, item title, variant title and SKU, or a workflow's name; finds, does not narrow                                                                                   | shop work | `ListSearch`, `searchTerm`                                                                                     |
| **default**          | what a list shows with no filter and no search                                                                                                                                                                    | shop work | `null` show (Making); `DEFAULT_WORKFLOWS_LIST_STATE`                                                           |
| **reconcile**        | make an order's runs agree with the order and the eligible workflows; idempotent                                                                                                                                  | shop work | `reconcileItem`, the run repository's `reconcileOrder`                                                         |
| **reconcile all**    | reconcile every stored open, paid order once, after anything that changes which workflows are eligible                                                                                                            | shop work | `Runs.reconcileAll`, the run repository's `reconcileAll`                                                       |
| **eligible**         | an active workflow that has a task and has every task on a team; only an eligible workflow creates runs                                                                                                           | shop work | `workflowIsEligible`, `EligibleContext`                                                                        |
| **match**            | an item and an eligible workflow: a product tag equals the workflow's tag and units to make are above zero                                                                                                        | shop work | `itemMatches`                                                                                                  |
| **multi-match**      | an item two or more eligible workflows match, with units to make and no run in any state                                                                                                                          | shop work | `multiMatchItems`, `OrderIssue` `multi_match`                                                                  |
| **units to make**    | what is left to make on an item: Shopify's current quantity                                                                                                                                                       | shop work | `unitsToMake`                                                                                                  |
| **setup**            | the three facts a shop needs before Baton does its work: a team with a member, an active workflow, a run; derived, never stored                                                                                   | shop work | `SetupFacts`, `setupIsComplete`                                                                                |
| **plan**             | the App Pricing tier a shop buys; never named on a screen                                                                                                                                                         | billing   | `Plan`, `PlanHandle`                                                                                           |
| **app subscription** | one shop's purchase of a plan, as the Partner API reports it; one or none                                                                                                                                         | billing   | `AppSubscription`, `ShopifyPartner.activeSubscription`                                                         |
| **billing cycle**    | one month of an app subscription; both meters start at zero                                                                                                                                                       | billing   | `ShopUsage` `cycleStartAt`, `cycleEndAt`; `BillingCycleInput`                                                  |
| **trial**            | the days before an app subscription's first billing cycle; nothing is billed                                                                                                                                      | billing   | `AppSubscription` `cycleStartAt` null                                                                          |
| **meter**            | a counter Shopify keeps per app subscription                                                                                                                                                                      | billing   | `USAGE_METER_ORDER`, `USAGE_METER_MEMBER`                                                                      |
| **counted order**    | an order Baton created a run for; one unit, once                                                                                                                                                                  | billing   | `ShopOrder.countedAt`, `makeUsageRepository`'s `countOrder`                                                    |
| **seat**             | one unit of the members meter; a cycle's seats are its highest member count                                                                                                                                       | billing   | `ShopUsage.seatsThisCycle`, `seatEventValue`                                                                   |
| **included**         | a plan's $0.00 first tier on a meter: a paid allowance, not a free tier                                                                                                                                           | billing   | `Entitlements`                                                                                                 |
| **usage event**      | one report of units to Shopify, queued until Shopify accepts it                                                                                                                                                   | billing   | `UsageEvent`, `makeBilling`'s `flushUsageEvents`, `ShopifyAppEvents`                                           |
| **expired event**    | a usage event dated before the current billing cycle; deleted at the next flush                                                                                                                                   | billing   | `usageEventIsExpired`                                                                                          |
| **lapsed**           | a shop with no app subscription: the gate answers `402`, `/app` goes to plan selection, members read Subscription inactive                                                                                        | billing   | `ShopAccessDenied` `402`, `CONNECTION_CLOSE_PAYMENT_REQUIRED`, `SubscriptionPlan`                              |
