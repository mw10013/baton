The verb

Start workflow · chosen

Names the outcome: a run exists and a team gets a queue entry. Pairs with Cancel. Works as a one-click button on a tag match later.

Assign workflow

Shopify admin vocabulary, but implies a setting on the item. Merchants then expect Unassign, which does not match cancelling a run with done steps.

Attach workflow

Today's word. Matches the code. Attach is what you do to a file, not to work.
